# Touchstone 3 — North Star Bakery

This project continues the four-page HTML-only Touchstone 2 website and adds shared, responsive CSS.

## Complete before submitting
1. Download the **Bakery_c.zip** supplied by Sophia and extract the real media files into `media/` (not a nested subfolder).
2. Open `index.html` in GitHub Codespaces and use its preview; check all four pages and the mobile view.
3. Commit and push all four `.html` files, `styles.css`, and the extracted media folder to a **public** GitHub repository.
4. Copy the repository URL into your Touchstone 3 explanation document. Add one **real screenshot** of the styled website from a browser preview.
5. Use the **official Sophia Touchstone 3 student template** if required; copy the design explanations from the supplied document into it.

**Note:** The form is HTML-only, with client-side validation; it is not connected to a server. Opening HTML files without the supplied media ZIP will show missing images/video.
